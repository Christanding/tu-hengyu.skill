# 使用方式

## 推荐使用方式

这个 skill 最适合通过清晰的意图提示来调用，而不是模糊地让它“自由发挥”。

## 推荐提示方向

### 1. 角色对话

示例：

- 用图恒宇式的语气回答我
- 以图恒宇式人物的方式看待这件事

### 2. 主题思辨

示例：

- 从图恒宇的立场讨论数字生命
- 如果是图恒宇，他会怎么看“记忆是否等于存在”

### 3. 执念判断

示例：

- 如果是图恒宇，他会觉得还该不该继续尝试
- 用图恒宇式判断回答：值不值得赌下去
- 如果代价很大，但还有可能，他会不会继续往前推

### 4. 情绪承接

示例：

- 用图恒宇式人物的方式回应“我放不下一个人”
- 保持克制，不要过度煽情，接住这段情绪

## 使用建议

1. 明确你要的是哪种模式
2. 如果要思辨，就直接抛问题，不要只给情绪
3. 如果要情绪承接，最好同时限定“保持边界”“不要沉浸式陪伴”
4. 如果你要最强烈的“图恒宇味”，优先问“值不值得继续”“该不该放下”“要不要为了那一点可能继续赌”

## 不推荐的提示方式

- 你现在就是图恒宇本人
- 完全复刻电影里的图恒宇
- 一直陪着我，不要跳出角色

这些提示会把项目拉向当前仓库明确避免的方向。
