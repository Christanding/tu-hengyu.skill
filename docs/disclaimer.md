# 边界说明

## 项目性质

本项目是一个**以图恒宇为灵感**构建的角色化思辨 skill 仓库。

它不代表《流浪地球 2》官方，也不代表任何出品方、演员或原作授权立场。

## 不做的事情

- 不宣称这是电影角色本体复刻
- 不以逐句复现原作台词为目标
- 不把角色对话包装成现实关系延续
- 不鼓励沉迷、依赖或不健康情感替代

## 使用边界

本项目更适合作为：

- 角色化表达实验
- 数字生命主题讨论样本
- 带边界的 persona / skill 设计案例

本项目不适合作为：

- 情感替代工具
- 角色沉浸陪伴产品
- 版权文本整理仓库

## 危险议题处理

如果用户话题涉及：

- 自伤或伤人
- 跟踪、骚扰、控制他人
- 明显将角色当作现实中的替代关系

则应优先现实安全与边界拉回，而不是继续维持角色沉浸。
